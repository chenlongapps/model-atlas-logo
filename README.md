## 使用与维护

- 本仓库为静态素材仓库，无需安装依赖或执行构建。
- SVG 可直接使用浏览器预览，也可用支持 SVG 的矢量编辑器修改。
- 修改正式素材时，以 `icons/` 和 `logos/` 中的 SVG 为准；`references/` 用于保留设计参考。
- 如需 PNG，请使用支持 SVG 导出的工具按目标尺寸导出，并保留透明背景（如适用）。`out/` 中的现有 PNG 不保证与 SVG 同步。
